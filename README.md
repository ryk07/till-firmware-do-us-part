One line, at most 200 characters: a wedding vow that survives a firmware update. I vow to love you through every firmware update — even the one that bricked our toaster, reset the Wi-Fi password, and still couldn't patch the way I look at you.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (override with `ENTRY_OUTPUT`).
